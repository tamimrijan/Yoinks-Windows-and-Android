# Changelog

## Android 1.0.0 - Yoinks comes to your phone

- Native Android app built with Jetpack Compose and Material 3 Expressive
- Same flow as Windows: paste a link, pick a resolution or MP3, download
- Share to Yoinks from YouTube, Instagram, TikTok, the browser or any app
- Downloads keep going in the background, with progress and Cancel in notifications
- Saves to Download/Yoinks so videos show up in Gallery and songs in music apps
- Expressive design: cookie and sunny shapes, wavy progress ring, shape-morphing buttons,
  spring motion, floating pill navigation, light and dark mode, optional Material You colours
- Built-in engine (Python, yt-dlp, FFmpeg, QuickJS), with yt-dlp updates from Settings
- Downloads tab with search, play, share, yoink again; About page with links to the author

## 1.0.0 - first release

Yoinks comes to Windows as a native desktop app.

- Paste a link from YouTube, X, Instagram, Threads, TikTok or 1,800+ other sites
- Offers to paste a video link you just copied
- Pick any resolution (with estimated sizes) or audio-only MP3
- Live progress: speed, time left, part 1 of 2 for HD merges, taskbar progress
- Cancel any time; half-downloaded files are cleaned up
- Downloads page with search, play, show in folder, yoink again, copy link
- "Yoink this" browser bookmark through the `yoinks:` link handler
- Settings: theme, download folder, clipboard offer, history, component updates
- Windows 11 look: Fluent design, Mica, iOS-style frosted glass, light and dark mode
- Setup wizard: install for me or everyone, pick the download folder, optional Deno for YouTube
- Clean uninstall that never touches your downloaded videos
- About page with links to the author
